# Embedding a diagram

Structura's read-only viewer lives at `/viewer`. It draws exactly what the editor draws — same
positions, same edge waypoints, the version the diagram has open — and never writes anything.
The **Share → Embed** dialog in the app generates both snippets below for the current diagram.

## 1. Diagram in the URL

The simplest option: the diagram is compressed into the URL fragment, so nothing is sent to a
server.

```html
<iframe
  src="https://structur.dev/viewer#data=<payload generated by the app>"
  width="100%"
  height="500"
  style="border: 0"
></iframe>
```

Long diagrams make long URLs; for large diagrams, or when the diagram comes from your own build
pipeline, use `postMessage` instead.

## 2. Diagram sent with `postMessage`

Point the iframe at `/viewer` with no fragment. The viewer posts `STRUCTURA_READY` to its parent
once it is listening, and accepts a `STRUCTURA_LOAD` message carrying a diagram as exported with
**Export → JSON**. It answers with `STRUCTURA_LOADED` (`success: true`, or `success: false` and an
`error` message when the payload is not a valid diagram).

```html
<iframe id="structura" src="https://structur.dev/viewer" width="100%" height="500"></iframe>
<script>
  const iframe = document.getElementById("structura");
  const diagram = /* the exported diagram JSON */;

  window.addEventListener("message", (event) => {
    if (event.source !== iframe.contentWindow) return;
    if (event.data?.type === "STRUCTURA_READY") {
      iframe.contentWindow.postMessage({ type: "STRUCTURA_LOAD", diagram }, "https://structur.dev");
    }
    if (event.data?.type === "STRUCTURA_LOADED" && !event.data.success) {
      console.error("Structura could not load the diagram:", event.data.error);
    }
  });
</script>
```

In React (for example in a Docusaurus page):

```jsx
import { useEffect, useRef } from "react";
import diagram from "./my-diagram.json";

const ORIGIN = "https://structur.dev";

export function ArchitectureDiagram() {
  const ref = useRef(null);

  useEffect(() => {
    const onMessage = (event) => {
      if (event.source !== ref.current?.contentWindow) return;
      if (event.data?.type === "STRUCTURA_READY") {
        ref.current.contentWindow.postMessage({ type: "STRUCTURA_LOAD", diagram }, ORIGIN);
      }
    };
    window.addEventListener("message", onMessage);
    return () => window.removeEventListener("message", onMessage);
  }, []);

  return <iframe ref={ref} src={`${ORIGIN}/viewer`} width="100%" height={500} />;
}
```

## Opening a flow

Add `flow=<flow id>` to the URL fragment (`/viewer#flow=<id>`, or `#data=…&flow=<id>` with an
embedded payload) to open the diagram with one of its flows ready to play.

## Self-hosting

Replace `https://structur.dev` with the origin where you deploy `dist/`. The viewer is part of
the same build; there is no separate artifact.
