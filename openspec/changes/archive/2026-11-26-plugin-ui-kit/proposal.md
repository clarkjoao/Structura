# Proposal

## Why

Plugins draw their panels, toolbar buttons and modals with hand-written Tailwind classes copied
from the host (`structura-plugin-example-ui` rebuilds a primary button from `bg-primary px-4
py-2 …`). Those classes only work while the host's own CSS happens to contain them — Tailwind
emits only the classes the host source uses — and every plugin re-implements focus rings,
disabled states and dark mode on its own. Plugins should look like Structura by using
Structura's components.

## What Changes

- Plugin API **1.18.0**: a curated **UI kit** of host components with stable, documented props:
  `Button`, `Input`, `Textarea`, `Label`, `Field`, `Checkbox`, `Switch`, `Select`, `Badge`,
  `Card`, `Tabs`, `Tooltip`, `Separator`, `Stack`.
- Reachable two ways, the same objects:
  - `api.ui.<Component>` — for no-build JavaScript plugins (`api.ui.CodeEditor` already lives
    there);
  - `import { Button } from "@structura/ui"` — for bundled plugins, as a build-time external
    bound to a host global (`__STRUCTURA_UI__`), exactly like `react`.
- Type declarations for the kit are part of `plugin.types.ts` (copied by `sync-types`), plus a
  `structura-ui.d.ts` module declaration for the `@structura/ui` import.
- The `structura-plugin-example-ui` plugin moves to the kit; `plugins/README.md` documents it and
  the theme tokens (`hsl(var(--primary))`, …) plugins may use for anything the kit lacks.

## Non-Goals

- Exposing the raw shadcn/Radix components (their props change when regenerated by the CLI).
- An icon set: plugins bundle the icons they use (`lucide-react` tree-shakes to a few KB).
- Dialogs: `api.overlay.openModal` already renders a host dialog.
- Shipping a Tailwind build to plugins.

## Capabilities

### Modified Capabilities

- `plugin-system`: the API gains the UI kit and its `@structura/ui` build contract.

## Impact

- New: `src/features/plugins/ui-kit/` (facade components), runtime global in `runtime-globals.ts`.
- Changed: `plugin.types.ts`, `plugin-api.ts` (`api.ui`), API version 1.18.0, the three plugins'
  synced types, `structura-plugin-example-ui` (uses the kit, `vite.config.js` external).
- No persistence or schema change.
